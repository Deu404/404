# 설비별 정상 범위 등록 완료 보고

2026-10-16. 적용 버전: normal-pattern-v1.

13개 설비에 관측 운전상태 0/1을 구분한 정상 참조 범위를 등록했다. 기존 Random Forest 모델의 탐지 결과에 설명 근거를 보태는 기능이며, 모델을 교체하거나 실제 고장·안전 한계를 확정하지 않는다.

## 산출과 검증

- 원본: test_data/clean_reference의 합성 정상 JSON 13개, 총 705,120행.
- 각 파일을 시간순 앞 60% 423,072행으로 중심·IQR 척도 산출, 다음 20% 141,024행으로 범위 보정, 마지막 20% 141,024행으로 독립 검증.
- 참조 산출·보정 기간: 2025-06-15 00:00:00~2025-06-17 12:15:55. 검증: 2025-06-17 12:16:00~2025-06-18 03:19:55.
- 전압·전류·전력·역률 등 원시 14항목과 계산 가능한 상별 전류 편차율을 사용. 단위가 확정되지 않은 원시 값은 변환하지 않았다.
- 보정 구간에서 한 행의 최대 표준화 편차의 99.5% 분위수로 범위를 고정. 정상 검증을 본 뒤 기준을 다시 맞추지 않았다.
- 분리된 정상 검증에서 643/141,024행 범위 이탈: 0.4560%. 모든 설비가 사전 수용 기준인 정상 검증 이탈률 1% 이하를 충족했다.
- Python 산출 결과와 TypeScript 런타임을 정상 141,024행·오류 포함 141,024행 전체에서 대조해 판정 건수 일치를 확인했다.

## 동작 범위와 한계

정상 범위 검사는 한 시점의 값 비교다. 정상 범위 안에 있는 센서 고정·시간 오류·누적전력량 정합성 등은 검사 범위 밖이며 기존 모델의 의심을 해제하지 않는다. 모든 오류에 대한 탐지 성능을 이 범위 검사의 성능으로 주장하지 않는다.

별도 오류 포함 검증 구간의 단독 범위·측정 유효성 검사: TP 1,988, FP 593, FN 9,549, TN 128,894, 재현율 17.23%, 정밀도 77.02%. 이 수치는 Random Forest 성능이 아니다. 값 고정 등 범위 밖 종류의 오류가 포함되어 단독 탐지기로 사용할 수 없다. 유형별 결과는 validation.json에 기록했다.

기존 대시보드의 2024년 12월 알림을 2025년 6월 참조와 비교하는 것은 과거 자료 설명용 대조다. 과거 시점에서 미래 자료 없이 검증한 성능으로 해석하지 않는다. 화면과 응답에 참조 기간 및 관측과의 시간 관계를 표시한다.

## 연결 및 확인

- 알림을 선택하면 /api/inspection에서 외부 AI 호출 없이 관측·기준을 조회하고 판정표를 표시한다.
- 실제 오류 주입 JSON을 조회할 때 is_anomaly·fault_fields·event_id 등 정답 메타데이터를 제거한다. 정상 참조를 실제 관측으로 대체하지 않는다.
- 이탈: 현재값·상하한·출처·운전상태를 제시하고 기록·재확인·조건 확인을 안내한다.
- 범위 안: 검사한 값의 범위 결과만 설명하고 모델이 의심한 시계열·시간·전력량 항목은 별도로 확인하도록 안내한다.
- 누락·비수치·미등록 상태·조회 실패: 정상으로 처리하지 않고 부족한 정보를 표시한다.
- 정상·범위 이탈·자료 누락·미등록 설비, 13개 설비의 관측 조회부터 도구 호출·가이드·응답까지 검증했다. 새 범위 판정의 AI 구간은 외부 전송 없는 모의 응답으로 검증했다. 실제 OpenAI 연결은 앞서 승인된 예측 조회 경로에서 확인한 상태다.
- 브라우저에서 실제 모델 알림 선택 후 15항목 판정표·현재값·상하한·참조 출처 표시를 확인했다.
